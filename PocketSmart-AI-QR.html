FAQ

What is PocketSmart AI?

PocketSmart AI is a project concept that combines expense tracking, budgeting, savings goals and AI-style recommendations in one web application.

What does the AI recommendation do?

It analyzes the income, expense and goal values entered by the user and produces practical budgeting and saving suggestions.

Are my analyses saved?

This prototype uses browser local storage, so saved analyses normally remain on the same browser and device until site data is cleared.

Can this be connected to a real AI API?

Yes. The frontend can be connected to a backend AI service such as a controlled Generative AI API in the full-stack version.

Is this a financial advisory service?

No. It is an educational project prototype. Recommendations are informational and should not be treated as professional financial advice.
